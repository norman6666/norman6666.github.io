# 芯问

面向嵌入式开发资料的本地 RAG 问答界面。

## 功能

- 上传 PDF、DOCX、TXT、Markdown、C/H 源文件
- 查看本地知识库和索引状态
- 针对指定手册或全部资料提问
- 展示回答所依据的文档、章节和页码
- 连接本机 em_rag 与 Ollama，不在网页端保存手册内容

## 本地开发

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

网站默认连接 `http://127.0.0.1:8765`。如果后端通过安全通道运行，可以在网站右上角设置中更换服务地址。
